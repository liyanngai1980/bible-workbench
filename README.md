# 研经工作台 (Bible Study Workbench)

一款现代、高效、高定制化的全功能圣经研读与释经工作台，灵感源自专业研经系统（如 Logos、YouVersion 及 Yanjing Tool），采用纯前端离线架构设计，完美适配并运行于 **GitHub Pages**。

在线演示地址：[https://liyanngai1980.github.io/bible-workbench/](https://liyanngai1980.github.io/bible-workbench/)

---

## ✨ 核心特色与功能亮点

### 1. 自动识别 Desktop macOS 与 iOS 移动视图 (Responsive & Device Adaptive)
- **设备智能识别**：系统自动检测用户运行环境（macOS 桌面、iOS iPhone / iPad、Android 设备及屏幕宽度），自动切换最佳排版。
- **专为手机打造的原生体验 (iOS Mobile View)**：
  - **iOS 底部快捷分页面板 (Bottom Tab Bar)**：毛玻璃半透明浮层，自适应 iOS Safe Area 底部安全区，单指轻触即可在「大纲 / 经文 / 对照 / 导论 / 注释」之间流畅切换。
  - **双重手机阅读模式**：
    1. **分页面板模式 (Tabs)**：单窗口全屏沉浸阅读，字体优雅通透，避免窄屏挤压。
    2. **卡片堆叠模式 (Card Stack)**：五大窗口垂直卡片排列，上下滑动一览无余。
       - **底部分页面板联动跳转**：在卡片堆叠模式下，点击底部 Tab（大纲/经文/对照/导论/注释），视图立即平滑定位滚动至该卡片，并伴随蓝色发光聚焦提示动画！
       - **卡片独立收起与展开**：每张卡片右上角均提供 `✕` 关闭按钮，点击后优雅收起并记忆状态；点击底部 Tab 或顶部开关可随时重新展开。
  - **手机版专属 Touch Hold and Drag**：在手机触摸屏上，**长按任意卡片顶部抓手（`⋮⋮`）约 180ms 即可进入悬浮拖曳状态，手指上下滑动即可自由调整窗口顺序**，松手即自动保存至本地！
- **桌面 / 手机视图片段一键切换**：顶部工具栏提供「🖥️ macOS 桌面 ↔ 📱 iOS 手机」切换开关，可在桌面端即时预览手机版，也可在 iPad 上随心切换。

### 2. 五大主窗口自由拖曳重排与布局储存 (Hold & Drag Movable Panels)
- **五大独立主检视窗口**：
  1. 📑 **大纲与札记 (Outlines & Notes)**：研读大纲、结构大纲、串珠经文、历史图表、高亮管理、个人札记
  2. 📖 **主读经文 (Primary Scripture)**：主译本经文阅读，支持 Strong's 原文字典点击、经文引用、语音朗读
  3. ⚖️ **对照经文 (Parallel Comparison)**：跨译本多栏逐节对照（如和合本、新译本、标准本、ESV、NASB）
  4. 🧭 **书卷导论与历史背景 (Intro & Background)**：成书背景、作者、时代脉络与神学要义
  5. 🔍 **逐节经文注释 (Verse Commentary)**：伯迪克、信徒注释、麦克阿瑟讲道解经专著
- **自由 Hold and Drag 拖曳定位**：按住任意窗口顶部的拖曳抓手（`⋮⋮`）即可自由左右拖动重排窗口顺序，自适应宽度！
- **布局记忆与永久储存 (Layout Persistence)**：拖动调整后的自定义窗口顺序自动保存至浏览器本地，重新加载或下次打开自动恢复；提供「↺ 重设布局」一键复原默认设置。
- **窗口独立显隐切换**：顶部工具栏提供 5 大窗口独立显隐开关（大纲 / 经文 / 对照 / 导论 / 注释），随需自由开合。

### 3. 双向经文滚动同步与同步开关键 (Synchronized Scrolling & Toggle)
- **经文、对照经文与逐节注释智能联动**：滑行主经文时，对照经文与右侧逐节注释栏自动平滑滚动对齐至相同节数并高亮显示！
- **独立 / 同步自由切换**：导航栏专属「🔗 同步滚动: 开 / 🔓 关」切换键，可随时一键锁定或解除联动，方便独立翻阅不同章节。

### 4. 经典多体裁经文库 (Landmark Biblical Texts)
开箱即用内置涵盖律法书、诗歌智慧书、福音书、保罗书信、普遍书信与启示文学的经典丰盛篇章：
- **创世记 1 (Genesis 1)**：万物创造周，包含希伯来原文词汇与神圣秩序大纲
- **诗篇 23 (Psalms 23)**：耶和华是我的牧者，大卫诗篇明珠与灵修注释
- **约翰福音 1 (John 1:1-18)**：太初有道道成肉身，基督神学巅峰
- **罗马书 8 (Romans 8)**：救恩确据、圣灵内住与得胜有余的凯歌
- **约翰一书 1 (1 John 1)**：亲眼见证生命之道与在光明中行
- **约翰二书 1 (2 John 1)**：在真理中持守爱心
- **约翰三书 1 (3 John 1)**：爱心接待宣教同工与警惕狂妄
- **启示录 21 (Revelation 21)**：新天新地与圣城耶路撒冷

### 5. 全局经文速查跳转 (Command Palette ⌘K / Ctrl+K)
- 键盘快捷键 **`⌘K` / `Ctrl+K`** 或点击顶部导航栏「速查」按钮即可唤出聚光灯（Spotlight）式速查指令面板。
- 支持智能中英文简称模糊匹配，例如：
  - `创 1` / `创 1:1` / `Gen 1` ➔ 直达创世记 1 章
  - `诗 23` / `Ps 23:1` ➔ 直达诗篇 23 篇
  - `约 3:16` / `Jn 3:16` ➔ 直达约翰福音 3:16
  - `罗 8:28` / `Rom 8:28` ➔ 直达罗马书 8:28
- 上下方向键选择，回车键直接平滑定位！

### 6. 经文彩色高亮与个人札记 (Highlighting & Personal Notes)
- 点击任意经文行，立即弹出悬浮工具栏：
  - **五色灵修荧光笔**：🟡 灵修感悟、🟢 神的应许、🔵 纯正真理、🔴 恩典救赎、🟣 诫命警勉、⚪ 清除高亮
  - **📝 研经札记**：针对每节经文撰写个人灵修心得、讲道笔记或神学观察，支持 Markdown 排版
- 左侧边栏集成专有管理面板：
  - **「高亮标注」** 栏目：集中浏览所有标记经节，支持一键点击跨书卷跳转
  - **「研经札记」** 栏目：按时间排序查阅全部笔记，支持 **一键导出为标准 Markdown 文件 (.md)**

### 7. 原生语音朗读播放器 (Web Speech API Audio Bible)
- 顶部集成音频控制栏：支持 **播放 / 暂停 / 停止** 与语速调节（0.8x / 1.0x / 1.2x / 1.5x）。
- 自动智能剥离 Strong 原文编码标签，保证发音流畅纯正。
- 自动识别语言环境：中文字本自动适配中文语音，英文字本自动适配英文语音。
- **实时随动高亮**：朗读时当前经文行呈现光晕跳动动画，并自动随播放进度平滑滚动到视野中央！

### 8. 多译本跨列并排比对配置器 (Parallel Configurator)
- 在模式 4 或并排标签页下，点击「并排配置」按钮，即可自选希望同屏跨列比对的译本（如 CUV、CNV、CSB、NET、NASB、ESV、OUS 及用户自定义上传译本）。
- 横向自适应表格排版，逐节对齐，便于比对不同翻译团队用词之微妙差异。

### 9. 精美经文分享卡片与规范引用 (Scripture Share Cards & Citations)
- 在悬浮工具栏中一键点击「卡片」，即可生成 Apple 风格极简美学经文分享卡片：
  - 支持 **清新浅色**、**古典羊皮**、**幽邃深色** 三种经典卡片视觉质感
  - 提供标准经文引用格式一键复制：`【约翰福音 1:1】太初有道，道与神同在，道就是神。（现代标点和合本）`
  - 提供 Markdown 引用格式一键复制：`> 太初有道，道与神同在，道就是神。\n> ——《约翰福音》1:1`

### 10. 全版本经文与全书释经注释零等待自动就绪 (Pre-bundled Zero-Wait Offline Experience)
- **开箱即用，免除手动下载困扰**：
  - 仓库内建静态完整数据集：**新标点和合本 (CUV 31,101 节全本)**、**ESV (31,086 节全本)**、**NASB (31,103 节全本)**、**KJV (36,812 节全本)**。
  - **全书 66 卷 20,780 条逐节研读释经与串珠注释**：全面覆盖创世记至启示录每一卷每一章每一节！
  - **渐进式后台静默预加载**：用户首次打开网站，前端引擎毫秒级呈现，后台自动将全本经文与全书释经写入浏览器本地 IndexedDB 数据库。
  - 翻阅任何书卷任何章节，无论是主读经文、多译本对照还是右侧逐节释经，**全部即时就绪，永不再提示未缓存**！
- **智能译本回退机制 (Intelligent Fallback)**：当多译本并排比对其他辅助译本时，若某些扩展译本尚未单独导入，系统自动优雅回退至和合本对应经文，杜绝出现空白横杠 `—`。

### 11. 史特郎原文字典系统 (Strong's Concordance Lexicon)
- 经文汇编译本 (OUS) 中带有点击式希腊文/希伯来文编号（如 `[G3056]`, `[G225]`, `[H7225]`, `[H3068]`）。
- 点击即可查看词根渊源、国际音标发音、词性语法、神学详解及全书出现频次。
- 支持 **「在圣经中查找此原文」**：一键在底部抽屉中检索包含该原文词汇的所有平行经节。

## 🚀 全本圣经与完整释经注释导入体系 (Full Bible & Commentary Library)

针对需要完整全本圣经（包含创世记至启示录全部 66 卷 1189 章，31,102 节经文）与全书释经注释的用户，本工作台提供三种极为便捷的安装与导入途径。所有数据永久保存在您本地浏览器的 **IndexedDB 离线数据库** 中，完全免除后端服务器依赖，速度极快。

点击右上角导航栏中的 **「⚙️ 管理与导入」** 即可呼出管理面板：

### 途径一：云端全本书库一键离线安装（最简单快捷，无需自己找文件）
在管理面板的 **「📚 云端全本书库」** 标签页中，直接点击 **「⚡ 一键安装到本地」**：
- 📖 **新标点和合本 (CUNPS 简体中文)**：完整新旧约 66 卷全本（31,102 节经文），内附数万条原文字义与平行经文详细串珠！
- 📖 **新标点和合本 (CUNP 繁体中文)**：完整 66 卷繁体全本。
- 📖 **中文思高圣经 (ChiSB 天主教全本 73 卷)**：权威天主教中文译本。
- 📖 **English Standard Version (ESV 全本 66 卷)**：经典原文字直译英文圣经。
- 📖 **King James Version (KJV 英王詹姆斯 1611)**：经典公版英文圣经全本。
- 📖 **World English Bible (WEB 现代公版全本)**：无版权限制的现代公版英文译本。
- 🔍 **和合本全书串珠释义宝典 (66 卷全本注释)**：提取自全本 31,102 节经文的详细串珠考据与神学释义，点击任意经文即可在右侧查看！
- 🔍 **马太·亨利全本释经集萃 (Matthew Henry's Commentary)**：涵盖圣经每一章的经典灵修与讲道解经。

> 💡 **离线包下载**：每部全本圣经卡片右下角均提供 **「💾 下载离线包 (.json)」** 按钮，可直接将纯净的完整 JSON 数据包保存至您的 Mac 或 iPhone「文件」App 中随时备用。

### 途径二：导入您自己的全本圣经文件（支持任意大文件）
在 **「导入本地圣经」** 标签页中，支持将外部获取的整本圣经文件（支持高达数十兆的大文件）直接拖入上传：
1. **标准 JSON 格式 (全本 31,102 节)**：
   ```json
   {
     "id": "LZZ",
     "name": "吕振中译本",
     "verses": {
       "1-1-1": "起初，神创造天地...",
       "66-22-21": "愿主耶稣的恩惠与众圣徒同在。阿们。"
     }
   }
   ```
2. **开放圣经 JSON 数组格式 (Bolls / OpenBible 格式)**：
   ```json
   [
     { "book": 1, "chapter": 1, "verse": 1, "text": "起初，神创造天地。", "comment": "详细注释..." }
   ]
   ```
   *注：若文件中的经文条目附带 `comment`（释经/串珠），系统将**自动同时提取并创建对应的全书释经注释库**，一次导入两全齐美！*
3. **全本 CSV / 表格格式**：
   每行一节经文，如 `1,1,1,起初，神创造天地。`
4. **USFM / OSIS 格式**：
   支持国际圣经公会与 Paratext 标准 `.usfm` / `.txt` 文件解析。

### 途径三：导入全书自定义释经与讲章注释
在 **「导入本地注释」** 标签页中，支持导入多书卷或全本注释：
```json
{
  "id": "calvin-commentary",
  "title": "加尔文圣经注释集",
  "author": "约翰·加尔文",
  "verses": {
    "1-1-1": "【创1:1释经】神用权能的话语创造万物...",
    "43-1-1": "【约1:1释经】太初之道证明基督与父同等的神性本体..."
  }
}
```

### 3. 数据备份与跨设备迁移
- **整站数据备份**：点击「导出整站用户数据备份 (.json)」，一键打包所有已导入的译本、个人札记与高亮。
- **一键恢复**：随时导入之前备份的 `.json` 文件，实现跨电脑、跨浏览器的数据同步与迁移。

## ⌨️ 全局快捷键速览 (Keyboard Shortcuts)

| 快捷键 | 功能操作 |
| :--- | :--- |
| **`⌘K` / `Ctrl+K`** | 打开经文全局速查（Command Palette） |
| **`[` 或 `←`** | 跳转至上一章 |
| **`]` 或 `→`** | 跳转至下一章 |

## 🛠️ GitHub Pages 部署说明

本项目采用纯静态单页架构设计，无任何构建编译依赖：

1. 克隆或推送本项目至 GitHub 仓库：
   ```bash
   git add .
   git commit -m "feat: enhance bible workbench"
   git push origin main
   ```
2. 进入 GitHub 仓库设置 **Settings** -> **Pages**。
3. 选择 **Source: Deploy from a branch**，分支选择 **main**，目录选择 `/ (root)`，点击 **Save**。
4. 部署完成后即可通过 `https://<用户名>.github.io/bible-workbench/` 访问。
