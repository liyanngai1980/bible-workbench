# 研经工作台 (Bible Study Workbench)

一款现代、高效、高定制化的全功能圣经研读与释经工作台，灵感源自专业研经系统（如 Yanjing Tool），采用纯前端离线架构设计，完美适配并运行于 **GitHub Pages**。

在线演示地址：[https://liyanngai1980.github.io/bible-workbench/](https://liyanngai1980.github.io/bible-workbench/) (或您的 GitHub 仓库 Pages 链接)

---

## ✨ 核心特色与功能亮点

### 1. 多栏联动经典工作区 (Multi-Panel Workspace)
- **四种工作区预设**：
  - **模式 1（经典三栏）**：大纲 (20%) | 经文 (50%) | 导论与注释 (30%)
  - **模式 2（研读双栏）**：经文 (45%) | 导论与注释 (55%)
  - **模式 3（专注注释）**：全宽研读导论与逐节释经专著
  - **模式 4（并排比对）**：多译本同屏跨列逐节对照 (Parallel Bible)
- **快捷切换**：随时一键折叠或展开「大纲栏」、「导论/注释栏」及「检索与词典抽屉」。
- **舒适阅读体验**：支持浅色 (Light)、羊皮纸护眼 (Sepia)、暗黑 (Dark) 三套主题，支持字号实时缩放（A- / A+）。

### 2. 强大的多译本与原文系统 (Multi-Versions & Strong's Lexicon)
- **内置开箱即用译本**：
  - 现代标点和合本 (CUV)
  - 圣经新译本 (CNV)
  - 中文标准译本 (CSB)
  - 中文 NET 圣经 (CNET)
  - 英文 NASB
  - 英文 ESV
  - 经文汇编译本 (Strong's OUS)
- **史特郎原文字典 (Strong's Concordance)**：
  - 经文中带有点击式原文编号（如 `[G4245]`, `[G27]`, `[G225]`）。
  - 点击任何原文字词，即刻呼出原文悬浮卡片及底部原文字典抽屉，包含希腊文/希伯来文字形、发音、词性、词根渊源、字义详释及出现频率统计。
  - 支持**一键反查**：在全本圣经中检索包含该原文词汇的所有经节。

### 3. 大纲体系与逐节注释同步 (Synchronized Outlines & Commentaries)
- **结构大纲体系**：内置《圣经研读大纲》（哈罗德·威尔明顿）、《结构分析大纲》、《串珠经文》(TSK)。点击大纲段落直接平滑滚动定位经文。
- **逐节注释联动**：内置唐纳德·伯迪克注释、信徒圣经注释、教牧讲道与解经等专著。点击经文区任意一节经文，右侧注释栏**自动同步对齐并高亮该节的释经内容**。

## 🚀 自定义导入体系 (Custom Bible & Commentary Import)

本系统最大的定制化特色在于：**允许用户无缝导入任意自定义圣经译本、个人研经笔记或神学注释**！所有导入的数据持久保存在您本地浏览器的 **IndexedDB 数据库**中，完全离线运行、安全可靠、无需任何后端服务器。

点击右上角导航栏中的 **「⚙️ 管理与导入」** 即可呼出管理面板：

### 1. 导入自定义圣经译本
支持三种导入格式（可在导入面板中一键下载示例模板）：

#### 格式 A：标准 JSON 格式 (推荐)
```json
{
  "id": "LZZ",
  "name": "吕振中译本",
  "abbreviation": "吕振中",
  "verses": {
    "64-1-1": "作长老的、写信给亲爱的该犹、就是我在真实中所爱的。",
    "64-1-2": "亲爱的、我祝你事事亨通，身体健壮，正如你的灵魂亨通一样。",
    "64-1-3": "有弟兄们来，见证你在真理中，正如你按真理而行，我就非常喜欢。"
  }
}
```
*注：经文键名格式为 `书卷号-章-节`（例如 `64-1-1` 即第 64 卷约翰三书第 1 章第 1 节）。*

#### 格式 B：CSV / 表格格式
每行一节经文，逗号分隔：
```csv
书卷号,章,节,经文内容
64,1,1,作长老的、写信给亲爱的该犹、就是我在真实中所爱的。
64,1,2,亲爱的、我祝你事事亨通，身体健壮，正如你的灵魂亨通一样。
```

#### 格式 C：单行文本格式
```text
约三 1:1 作长老的、写信给亲爱的该犹、就是我在真实中所爱的。
约三 1:2 亲爱的、我祝你事事亨通，身体健壮，正如你的灵魂亨通一样。
```

### 2. 导入自定义解经注释与导论
支持将您自己撰写的讲道笔记、灵修随笔或学者专著导入为独立注释模块：
```json
{
  "id": "calvin-notes",
  "title": "加尔文解经集萃",
  "author": "约翰·加尔文",
  "book": 64,
  "intro": "约翰在此教导我们应当在真实无伪的爱心接待中见证主道...",
  "verses": {
    "1": "【第1节评注】神圣的长老职分建立在服事众人的谦卑品格中。",
    "2": "【第2节评注】身体与灵魂的康泰乃是信徒在地上事奉主不可或缺的保障。"
  }
}
```

### 3. 数据备份与跨设备迁移
- **整站数据备份**：点击「导出整站用户数据备份 (.json)」，一键打包所有已导入的译本与笔记。
- **一键恢复**：随时导入之前备份的 `.json` 文件，实现跨电脑、跨浏览器的数据同步与迁移。

## 🛠️ GitHub Pages 部署说明

本项目采用纯静态单页架构设计，无任何构建编译依赖：

1. 在 GitHub 上创建新仓库（如 `bible-workbench`）。
2. 将本项目所有文件推送至该仓库的 `main` 分支：
   ```bash
   git remote add origin git@github.com:liyanngai1980/bible-workbench.git
   git push -u origin main
   ```
3. 打开 GitHub 仓库页面，进入 **Settings** -> **Pages**。
4. 在 **Build and deployment** 下选择 **Branch: main**，路径选择 `/ (root)`，点击 **Save**。
5. 稍等约 1 分钟即可在 `https://liyanngai1980.github.io/bible-workbench/` 访问您的专属研经工作台！
