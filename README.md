# 研经工作台 (Bible Study Workbench)

一款现代、高效、高定制化的全功能圣经研读与释经工作台，灵感源自专业研经系统（如 Logos、YouVersion 及 Yanjing Tool），采用纯前端离线架构设计，完美适配并运行于 **GitHub Pages**。

在线演示地址：[https://liyanngai1980.github.io/bible-workbench/](https://liyanngai1980.github.io/bible-workbench/)

---

## ✨ 核心特色与功能亮点

### 1. 五大主窗口自由拖曳重排与布局储存 (Hold & Drag Movable Panels)
- **五大独立主检视窗口**：
  1. 📑 **大纲与札记 (Outlines & Notes)**：研读大纲、结构大纲、串珠经文、历史图表、高亮管理、个人札记
  2. 📖 **主读经文 (Primary Scripture)**：主译本经文阅读，支持 Strong's 原文字典点击、经文引用、语音朗读
  3. ⚖️ **对照经文 (Parallel Comparison)**：跨译本多栏逐节对照（如和合本、新译本、标准本、ESV、NASB）
  4. 🧭 **书卷导论与历史背景 (Intro & Background)**：成书背景、作者、时代脉络与神学要义
  5. 🔍 **逐节经文注释 (Verse Commentary)**：伯迪克、信徒注释、麦克阿瑟讲道解经专著
- **自由 Hold and Drag 拖曳定位**：按住任意窗口顶部的拖曳抓手（`⋮⋮`）即可自由左右拖动重排窗口顺序，自适应宽度！
- **布局记忆与永久储存 (Layout Persistence)**：拖动调整后的自定义窗口顺序自动保存至浏览器本地，重新加载或下次打开自动恢复；提供「↺ 重设布局」一键复原默认设置。
- **窗口独立显隐切换**：顶部工具栏提供 5 大窗口独立显隐开关（大纲 / 经文 / 对照 / 导论 / 注释），随需自由开合。

### 2. 双向经文滚动同步与同步开关键 (Synchronized Scrolling & Toggle)
- **经文、对照经文与逐节注释智能联动**：滑行主经文时，对照经文与右侧逐节注释栏自动平滑滚动对齐至相同节数并高亮显示！
- **独立 / 同步自由切换**：导航栏专属「🔗 同步滚动: 开 / 🔓 关」切换键，可随时一键锁定或解除联动，方便独立翻阅不同章节。

### 2. 经典多体裁经文库 (Landmark Biblical Texts)
开箱即用内置涵盖律法书、诗歌智慧书、福音书、保罗书信、普遍书信与启示文学的经典丰盛篇章：
- **创世记 1 (Genesis 1)**：万物创造周，包含希伯来原文词汇与神圣秩序大纲
- **诗篇 23 (Psalms 23)**：耶和华是我的牧者，大卫诗篇明珠与灵修注释
- **约翰福音 1 (John 1:1-18)**：太初有道道成肉身，基督神学巅峰
- **罗马书 8 (Romans 8)**：救恩确据、圣灵内住与得胜有余的凯歌
- **约翰一书 1 (1 John 1)**：亲眼见证生命之道与在光明中行
- **约翰二书 1 (2 John 1)**：在真理中持守爱心
- **约翰三书 1 (3 John 1)**：爱心接待宣教同工与警惕狂妄
- **启示录 21 (Revelation 21)**：新天新地与圣城耶路撒冷

### 3. 全局经文速查跳转 (Command Palette ⌘K / Ctrl+K)
- 键盘快捷键 **`⌘K` / `Ctrl+K`** 或点击顶部导航栏「速查」按钮即可唤出聚光灯（Spotlight）式速查指令面板。
- 支持智能中英文简称模糊匹配，例如：
  - `创 1` / `创 1:1` / `Gen 1` ➔ 直达创世记 1 章
  - `诗 23` / `Ps 23:1` ➔ 直达诗篇 23 篇
  - `约 3:16` / `Jn 3:16` ➔ 直达约翰福音 3:16
  - `罗 8:28` / `Rom 8:28` ➔ 直达罗马书 8:28
- 上下方向键选择，回车键直接平滑定位！

### 4. 经文彩色高亮与个人札记 (Highlighting & Personal Notes)
- 点击任意经文行，立即弹出悬浮工具栏：
  - **五色灵修荧光笔**：🟡 灵修感悟、🟢 神的应许、🔵 纯正真理、🔴 恩典救赎、🟣 诫命警勉、⚪ 清除高亮
  - **📝 研经札记**：针对每节经文撰写个人灵修心得、讲道笔记或神学观察，支持 Markdown 排版
- 左侧边栏集成专有管理面板：
  - **「高亮标注」** 栏目：集中浏览所有标记经节，支持一键点击跨书卷跳转
  - **「研经札记」** 栏目：按时间排序查阅全部笔记，支持 **一键导出为标准 Markdown 文件 (.md)**

### 5. 原生语音朗读播放器 (Web Speech API Audio Bible)
- 顶部集成音频控制栏：支持 **播放 / 暂停 / 停止** 与语速调节（0.8x / 1.0x / 1.2x / 1.5x）。
- 自动智能剥离 Strong 原文编码标签，保证发音流畅纯正。
- 自动识别语言环境：中文字本自动适配中文语音，英文字本自动适配英文语音。
- **实时随动高亮**：朗读时当前经文行呈现光晕跳动动画，并自动随播放进度平滑滚动到视野中央！

### 6. 多译本跨列并排比对配置器 (Parallel Configurator)
- 在模式 4 或并排标签页下，点击「并排配置」按钮，即可自选希望同屏跨列比对的译本（如 CUV、CNV、CSB、NET、NASB、ESV、OUS 及用户自定义上传译本）。
- 横向自适应表格排版，逐节对齐，便于比对不同翻译团队用词之微妙差异。

### 7. 精美经文分享卡片与规范引用 (Scripture Share Cards & Citations)
- 在悬浮工具栏中一键点击「卡片」，即可生成 Apple 风格极简美学经文分享卡片：
  - 支持 **清新浅色**、**古典羊皮**、**幽邃深色** 三种经典卡片视觉质感
  - 提供标准经文引用格式一键复制：`【约翰福音 1:1】太初有道，道与神同在，道就是神。（现代标点和合本）`
  - 提供 Markdown 引用格式一键复制：`> 太初有道，道与神同在，道就是神。\n> ——《约翰福音》1:1`

### 8. 云端圣经一键调取与离线缓存 (Online Sync & IndexedDB)
- 当用户切换至尚未本地缓存的书卷或章节时，阅读区呈现友好提示卡片。
- 支持一键在线连接全球圣经开放数据云（Bolls.life）：
  - 支持和合本（简体 CUNPS / 繁体 CUNP）、思高本、ESV、NASB、KJV 等主流译本
  - 获取后 **自动永久缓存写入浏览器本地 IndexedDB 数据库**，此后完全离线可用！

### 9. 史特郎原文字典系统 (Strong's Concordance Lexicon)
- 经文汇编译本 (OUS) 中带有点击式希腊文/希伯来文编号（如 `[G3056]`, `[G225]`, `[H7225]`, `[H3068]`）。
- 点击即可查看词根渊源、国际音标发音、词性语法、神学详解及全书出现频次。
- 支持 **「在圣经中查找此原文」**：一键在底部抽屉中检索包含该原文词汇的所有平行经节。

## 🚀 自定义导入体系 (Custom Bible & Commentary Import)

本系统最大的定制化特色在于：**允许用户无缝导入任意自定义圣经译本、个人研经笔记或神学注释**！所有导入的数据持久保存在本地浏览器的 **IndexedDB 数据库**中，完全离线运行、安全可靠、无需任何后端服务器。

点击右上角导航栏中的 **「⚙️ 管理与导入」** 即可呼出管理面板：

### 1. 导入自定义圣经译本
支持三种导入格式（可在导入面板中一键下载示例模板）：
- **格式 A：标准 JSON 格式 (推荐)**
- **格式 B：CSV / 表格格式**
- **格式 C：单行文本格式**

### 2. 导入自定义解经注释与导论
支持将您自己撰写的讲道笔记、灵修随笔或学者专著导入为独立注释模块。

### 3. 数据备份与跨设备迁移
- **整站数据备份**：点击「导出整站用户数据备份 (.json)」，一键打包所有已导入的译本、个人札记与高亮。
- **一键恢复**：随时导入之前备份的 `.json` 文件，实现跨电脑、跨浏览器的数据同步与迁移。

## ⌨️ 全局快捷键速览 (Keyboard Shortcuts)

| 快捷键 | 功能操作 |
| :--- | :--- |
| **`⌘K` / `Ctrl+K`** | 打开经文全局速查（Command Palette） |
| **`[` 或 `←`** | 跳转至上一章 |
| **`]` 或 `→`** | 跳转至下一章 |
| **`j` 或 `↓`** | 选择并聚焦下一节经文 |
| **`k` 或 `↑`** | 选择并聚焦上一节经文 |
| **`Space` (空格)** | 开始 / 暂停当前章节语音朗读（焦点在输入框时除外） |
| **`1` / `2` / `3` / `4`** | 切换工作区模式（1:经典三栏, 2:研读双栏, 3:专注注释, 4:并排比对） |
| **`ESC`** | 关闭当前打开的速查面板或弹窗 |

## 🛠️ GitHub Pages 部署说明

本项目采用纯静态单页架构设计，无任何构建编译依赖：

1. 克隆或推送本项目至 GitHub 仓库：
   ```bash
   git add .
   git commit -m "feat: enhance bible workbench"
   git push origin main
   ```
2. 进入 GitHub 仓库设置 **Settings** -> **Pages**。
3. 选择 **Source: Deploy from a branch**，分支选择 **main**，目录选择 `/ (root)`，点击 **Save**。
4. 部署完成后即可通过 `https://<用户名>.github.io/bible-workbench/` 访问。
